# 《重返高三》全书大纲

## 全书结构

```
卷1：高三逆袭（ch1-100）—— 从倒数到状元，暗中布局
卷2：大学崛起（ch101-200）—— 创业+投资+人脉网
卷3：商业帝国（ch201-320）—— 复仇+财富+权力
卷4：终局之战（ch321-400）—— 赵家对决+圆满结局
```

---

## 卷一：高三逆袭（ch1-100）

### 核心目标
- 高考逆袭：从班级中游→全省理科状元
- 暗中布局：收赵世杰+刘子豪+苏老师，建立初始班底
- 财富起点：用前世知识说服父亲投资东江房产，压岁钱+分红攒下第一笔启动资金（约5万）
- 情感线：与林若溪建立联系，但不过度推进（高考前不谈恋爱）
- 暗线：逐步发现前世被背叛的真相更多层次——王浩从高中就开始了

### 情绪弧线
```
ch1-10：  重生冲击+摸底考逆袭 → 震惊全班
ch11-30： 布局收小弟+期中崛起 → 进入年级前十
ch31-50： 第一次被打压+反击 → 站稳脚跟
ch51-70： 寒假布局+模拟考封神 → 年级前三
ch71-90： 高考冲刺+暗线推动 → 各方势力开始注意到主角
ch91-100：高考+全省状元 → 卷一最高潮
```

### 分阶段详细

#### 阶段1：重生冲击（ch1-10）
- ch1：重生醒来，确认时间
- ch2-3：适应高三生活，发现"兄弟"王浩的面具
- ch4-5：摸底考试，精准控分——不考第一，考进前二十（留后手）
- ch6-7：第一次接触赵世杰，建立联系
- ch8-9：网吧找刘子豪，第一次提示LOL方向
- ch10：被班主任苏老师单独谈话——他发现主角"不一样了"

#### 阶段2：暗中布局（ch11-30）
- ch11-13：以辅导为名，实际在"教"赵世杰（iOS/Android开发方向）
- ch14-16：与李阳的第一次冲突（嘲讽赵世杰→主角反击→全班震惊）
- ch17-19：林若溪第一次正面交集（图书馆偶遇→发现她的困境）
- ch20-22：期中考试成绩逆袭——年级第八，全班第二（控分）
- ch23-25：苏老师母亲病情暴露，主角提供"偏方"（实际是前世医学知识）
- ch26-28：寒假前布局：让赵世杰寒假做一个App原型；主角整理2010-2015东江房产升值预测表
- ch29-30：寒假开始，主角用"高考状元预测"说服父亲投资东江新区楼盘（前世2011年暴涨），压岁钱+父亲给的"奖励"共5万，作为第一笔启动资金

#### 阶段3：被打压与反击（ch31-50）
- ch31-33：下学期开学，王浩开始暗中介入——在苏老师面前"无意"提到主角寒假没复习
- ch34-36：年级主任老周找主角谈话，暗示"不要搞歪门邪道"
- ch37-40：第一次模拟考——主角考了年级第一，全校震动
- ch41-43：王浩开始联合李阳打压主角，散布"陈默作弊"的谣言
- ch44-46：主角不辩解，用第二次模拟考—年级第一+超第二名15分—回应
- ch47-49：苏老师正式向主角袒露母亲病情，主角提出一个"建议"——让赵世杰做一个医疗预约App
- ch50：父亲的东江新区房产半年涨了40%——主角的5万启动资金+父亲给的10万分红=15万。18岁高中生，身价15万。这是第一桶金。

#### 阶段4：高考前（ch51-70）
- ch51-53：主角用15万启动更多布局：追加东江核心地段小户型投资+建议父亲进军省城市场
- ch54-56：王浩开始慌了——他发现无论怎么搞小动作，主角都不为所动
- ch57-59：第三次模拟考——主角稳居年级第一，已经开始有人把他当状元候选人
- ch60-62：林若溪主动找主角请教数学。她不知道——主角前世暗恋她三年，现在终于可以心平气和地和她说话。
- ch63-65：苏老师的母亲病情好转（偏方有效），苏老师对主角感激不尽
- ch66-68：高考前一个月——全校动员大会，主角作为学生代表发言
- ch69-70：高考倒计时7天。暗线伏笔：王浩打了一个神秘电话——"赵哥，陈默有问题……"

#### 阶段5：高考（ch71-90）
- ch71-74：高考前两天——主角心态最平静，但蝴蝶效应开始影响记忆（部分题目模糊了）
- ch75-78：高考第一天：语文（正常）+ 数学（用前世记忆确认最后一道大题压轴题思路，写出完美解答）
- ch79-82：高考第二天：理综（用前世知识精确踩点得分）+ 英语（轻松）
- ch83-85：高考结束——全班狂欢。主角没有参加聚会，而是去了网吧找刘子豪——LOL国服即将上线。
- ch86-88：王浩在高考后找主角"叙旧"——主角第一次对他露出真正的眼神。"王浩——以后，各走各的路吧。"王浩愣住了。
- ch89-90：高考成绩公布前夜。主角做了一个梦——梦到前世的车祸。醒来后，眼神更冷了。

#### 阶段6：状元（ch91-100）
- ch91-93：高考出分——全省理科状元，总分729（满分750）。全校沸腾，全市新闻。
- ch94-95：苏老师在全校大会上宣布——"陈默，省状元，东江一中建校以来第一个。"
- ch96-97：王浩假惺惺祝贺，主角只回了一句："谢谢。大学见。"（两人都考上了京城的大学——王浩在主角的"推荐"下报了另一所）
- ch98-99：暑假——主角正式启动商业计划。带赵世杰+刘子豪到京城，见早期的天使投资人。
- ch100：卷一结尾——主角站在清华校门前，回头看了一眼天空。"这辈子——不会重蹈覆辙。"

## 卷二：大学崛起（ch101-200）

### 核心目标
- 清华四年：建立京城顶级人脉网
- 商业起步：赵世杰的第一个App上线→被收购，第一桶金百万级
- 地产运作：2011-2013年在学期间持续布局东江+京城周边房产，利用家庭资金杠杆
- 投资布局：2014年A股牛市配资入场，2015年股灾前精准清仓
- 复仇暗线：发现王浩背后确实是赵家——前世害死自己的人已经开始注意他了

### 关键节点
| 章节 | 事件 |
|------|------|
| ch101-110 | 清华新生，结识京城太子圈 |
| ch111-130 | 赵世杰App上线→被腾讯收购，300万 |
| ch131-150 | 东江+京城房产大幅升值，身价突破500万→开始接触天使投资圈 |
| ch151-170 | 2014年A股牛市，配资入场 |
| ch171-190 | 王浩开始动用赵家资源打压主角 |
| ch191-200 | 卷二结尾：2015年6月股灾前精准清仓，主角身价过亿 |

---

## 卷三：商业帝国（ch201-320）

### 核心目标
- 2015-2020：建立自己的商业帝国（科技+地产+金融）
- 地产布局：2015股灾后资金转入一线城市豪宅+商业地产，2016-2017暴涨周期
- 正面与王浩/赵家对抗
- 收购周氏地产（东江最大开发商），回到家乡完成复仇第一站
- 与林若溪正式确立关系

---

## 卷四：终局之战（ch321-400）

### 核心目标
- 全面揭开赵家20年的黑暗历史
- 最终对决：商业战+法律战+公开战
- 复仇完成，王浩入狱，赵家核心覆灭
- 结局：主角回到东江一中，见到苏老师。"老师——我说过的——我会回来。"
- 番外：多年以后，主角的儿子上了同一所高中……
