# 《重返高三》人物圣经

## 主角

### 陈默（前世→今生）
| 维度 | 前世（1989-2026） | 今生（重生后） |
|------|------------------|---------------|
| 年龄 | 36岁（2026年死时） | 18岁身体，36岁灵魂 |
| 外貌 | 中年发福，普通面相 | 高三学生，清瘦，五官端正但不起眼 |
| 性格 | 温和懦弱，讨好型人格，被背叛后变得阴郁 | **表面低调寡言，内心杀伐果断** |
| 核心欲望 | 复仇+不再重蹈覆辙+保护前世亏欠的人 |
| 最大恐惧 | 蝴蝶效应导致无法掌控未来 |
| 习惯 | 前世：讨好式微笑 / 重生后：**左手转笔（思考时）、说话点到为止、眼睛看人时很静** |

**前世悲剧复盘：**
- 2010年高考：发挥失常，差一本线3分，去了二本。父亲大病，家道中落。
- 大学四年：自卑内向，暗恋校花林若溪但从未表白。
- 2014-2016：创业失败，被"兄弟"王浩拉入传销式项目，亏光积蓄。
- 2018年：发现女友和"兄弟"王浩的背叛——两人早就勾结，当年那个"创业项目"根本就是局。
- 2020-2025：试图复仇，却发现王浩背后还有更大的势力（京城赵家旁系），彻底绝望。
- 2026年3月15日：下班路上被大货车"意外"撞死。临死前听到一句话——"陈默，你不该查赵家的东西。"

**重生后性格转变：**
- 不再讨好任何人
- 说的每句话都不超过必要的信息量
- 看人的眼神很静，像在看一局已经下到终盘的棋
- 偶尔会露出前世36岁的疲惫——但在18岁的脸上，别人只觉得"陈默最近变深沉了"

## 核心配角（前世→今生）

### 1. 王浩 — 前世"兄弟" / 今生最大仇人（隐藏态）
| 维度 | 设定 |
|------|------|
| 2010年身份 | 同班同学，主角的"铁哥们" |
| 外表 | 帅气阳光，嘴甜会来事，班主任最喜欢的学生之一 |
| 前世结局 | 2018年联手主角女友背叛，后攀上赵家，2026年已是身价数亿的商人 |
| 前世与主角的关系 | 2010-2018年，表面上是主角最好的朋友。实际上王浩从一开始就在"用"主角——主角老实、好说话、不会拒绝。高考前，王浩"借"了主角的复习笔记，然后在考试当天故意迟到让主角分心（主角前世一直不知道）。 |
| 今生主角的态度 | 保持表面友好，暗中布局——前世那个"借笔记"的陷阱，今生的回复是："行。不过我的笔记不全——你最好自己再看看。"（轻描淡写划清边界） |

### 2. 林若溪 — 校花 / 前世暗恋对象
| 维度 | 设定 |
|------|------|
| 2010年身份 | 文科班高三（1）班，公认校花 |
| 外貌 | 清冷型，鹅蛋脸，丹凤眼，不爱笑 |
| 家境 | 父亲经营一家小建材公司（陈氏建材），2012年后陷入困境 |
| 前世结局 | 大学毕业后嫁给富二代，2019年丈夫破产+出轨，离婚独自带娃，2026年开了一家小花店维生 |
| 前世与主角的关系 | 主角暗恋她三年，从未表白。她其实知道——但不是"看不上"，而是她父亲说过"高考前不许谈恋爱"。高考后各奔东西。 |
| 今生设定 | 主角重生后不再暗恋——但他知道她父亲的建材公司会在2012年陷入危机。这次他想帮她，但不是以追求者的身份——至少一开始不是。 |

### 3. 赵世杰 — 前世"大佬" / 将被撬动的杠杆
| 维度 | 设定 |
|------|------|
| 2010年身份 | 高三（7）班，胖、戴厚眼镜、被全班嘲笑"赵猪" |
| 特长 | 编程天才，13岁就会写C++，但极度自卑 |
| 前世结局 | 2012年高考考入浙大计算机系，2015年开发了一款工具App被大厂收购，2018年成为独角兽公司CTO，2020年身价过10亿。但——2022年因过度劳累心脏病突发，38岁猝死。 |
| 前世与主角的关系 | 主角是全班唯一不嘲笑他的人——但也从未真正帮助过他。前世主角回忆时，赵世杰的名字出现在新闻讣告上。那是主角为数不多的"良心不安"。 |
| 今生设定 | 主角在开学第一天就坐在赵世杰旁边。"你好。我叫陈默。你写的那个扫雷外挂——能不能教教我。" ——一句话绑定未来CTO。 |

### 4. 刘子豪 — 网瘾少年 / 未来电竞冠军
| 维度 | 设定 |
|------|------|
| 2010年身份 | 主角邻居+发小，高二辍学，天天泡在"星辰网吧" |
| 特长 | 游戏天赋极高，DNF全国排名前50，LOL韩服测试期已上王者 |
| 前世结局 | 2018年LPL夺冠，签约费800万，2020年被俱乐部坑、合同陷阱导致职业生涯终结，2023年开了一家小网吧维生 |
| 前世与主角的关系 | 兄弟。主角大学时刘子豪常给他打钱。主角对不起他——2019年刘子豪被合同纠纷困住时，主角正因为自己的事情焦头烂额，没帮上忙。 |
| 今生设定 | 主角重生后，开学第二周就去了星辰网吧。"刘子豪。别打DNF了。LOL——明年国服上线——你打ADC。合同的事——以后我来谈。" |

### 5. 苏老师（苏明远） — 班主任 / 第一个"合伙人"
| 维度 | 设定 |
|------|------|
| 2010年身份 | 高三（7）班班主任，数学老师，35岁 |
| 性格 | 严肃、负责、但不死板。对每个学生的上线预估都记在本子上 |
| 前世结局 | 2016年辞职下海，2018年创业失败，2020年回老家开了家补习班 |
| 前世与主角的关系 | 前世主角对他只有敬畏。但他不知道——苏老师辞职是因为母亲癌症需要钱，而他从来没跟任何人提过。 |
| 今生设定 | 主角注意到苏老师每周五下午都会去肿瘤医院——前世他母亲2013年去世，苏老师那时已经辞职了。主角在开学两周后找到苏老师："老师——你母亲的事——我可以帮忙。不是借钱——是想办法。" |

## 反派体系

### 卷一反派（高中阶段）
| 人物 | 身份 | 与主角的冲突 | 作用 |
|------|------|-------------|------|
| **王浩** | 同班"兄弟" | 前世最大仇人，但主角暂时不揭穿 | 贯穿全书的暗线反派，卷一表现为"表面兄弟" |
| **李阳** | 同班富二代 | 看不起主角，嘲笑赵世杰，调戏林若溪 | 卷一前期小反派，被主角第一次打脸 |
| **年级主任老周** | 学校管理层 | 保守刻板，对差生有偏见 | 中期小反派，被主角成绩打脸 |
| **赵家势力（暗线）** | 京城赵家旁系 | 前世害死主角的幕后黑手 | 卷一仅暗示，不做直接冲突 |

### 后续卷反派（大学及以后）
| 卷 | 反派 | 身份 |
|----|------|------|
| 卷二 | 王浩+赵家旁系 | 大学里王浩也考上同城大学，继续纠缠 |
| 卷三 | 赵家核心 | 商业层面的对抗 |
| 卷四 | 国际资本 | 更大格局的对手 |
