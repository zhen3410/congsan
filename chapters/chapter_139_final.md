# 沙龙

周五。清华科技园。下午两点。

郑国平的沙龙在地下一层。不是会议室——是一个开放空间。白色墙面。灰色地毯。十几张圆桌。每张桌上一个名牌。顾屿找到自己的——「合理科技。顾屿。」旁边是赵世杰的名牌——没有公司名。只有三个字。「赵世杰。」

赵世杰把青轴键盘放在桌上。动作很轻——像在放一只还没出壳的鸟。

"紧张。"

"不紧张。"

"你手在抖。"

"键盘太重了。"

顾屿没说话。自己去倒了杯咖啡。黑咖啡。不加糖。回头看了一眼全场——三十多个人。一半是投资人——年过四十，穿深色西装，手里拿着名片夹。一半是创业者——二十出头，穿T恤牛仔裤，手里拿着笔记本电脑。有人在看手机。有人在改PPT。有一个女生坐在角落里——面前一台MacBook——在看代码。不是改PPT。

郑国平走上台。五十出头。花白头发。圆框眼镜。说话不快——但每句话都像钉在墙上。

"今天季度沙龙——主题——「2010年——移动互联网前夜。」2010年不是2014年。智能手机还不普及。3G网速像拨号。但明年——2011——安卓手机降价到千元线。用户会从一亿涨到五亿。在座的各位——不管你是投资人还是创业者——如果你现在做的不是移动端——五年后你会后悔。"

台下有人举手。"郑总——你说的是互联网——但今天的创业者里——有做大学生的排课系统。有做本地商户优惠券。有做少儿编程教育的。这些——算移动互联网吗。"

"算。不是因为赛道在移动端——是用户群明年人手一部千元安卓机。今天在PC上用你的产品——明天打开手机——第一个想起来的还是你。这不只是技术迁移——是心智占领。"

顾屿听完。把咖啡杯放下。郑国平的判断——和前世一模一样。2010年——所有人都在争论移动互联网到底有多快到来。只有少数人赌对了——郑国平是其中一个。

下午三点。自由交流时间。

郑国平走到顾屿面前。没握手——先看人。看了五秒。然后说了一句话。

"你不是十八岁。"

顾屿没动。也没说话。

"你做事的方式——不是大一新生的方式。三个月——签下三个天使轮。截胡赵氏三个项目。让赵建斌砸了两个杯子——其中一个青花瓷。你背后的逻辑——太成熟。成熟得不像刚成年。"

"可能是少年老成。"

"不是。少年老成的人——会紧张。会想在投资人面前证明自己。你——不紧张。也不证明。你坐在这里——像来开一场已经开过很多次的会。"

顾屿端起咖啡喝了一口。然后说。

"郑总。你投的第一个项目——是1998年。一个做论坛的。创始人比你大十岁。那年你三十八。所有人说你疯了——投一个比你大的人。你跟他们说——'我投的不是年龄——是判断。'"

郑国平没说话。但眼睛里的东西变了。不是惊讶——是确认。他在确认一件事——顾屿做过功课。很深。

"你怎么知道。"

"查过。公开资料里没有——但在清华经管学院——有一个关于国内天使投资发展史的课题。课题里提到你的第一笔投资。没有写金额——但写了时间。1998年。秋天。"

那个课题——前世2014年才发表。这辈子——还不存在。但郑国平不会去查——因为2010年的清华——和课题有关的人还没开始做这个课题。他们不知道这个课题将来会存在——更不知道它会被提前引用。

郑国平坐下来。面前是赵世杰的键盘。

"你带来的这个人——能做什么。"

顾屿看向赵世杰。赵世杰推了一下眼镜。把键盘接上笔记本电脑。打开终端。然后回头看顾屿。

顾屿点头。

赵世杰敲了第一行代码。青轴的声音——在安静的地下空间里——很脆。像有人在用指关节敲木头。不是紧张——是节奏。

旁边两桌的人停下来。看过来。

五分钟。赵世杰没说话。屏幕上的代码在长——从空白变成一段完整的异步任务调度框架。函数名。回调。错误处理。注释——只有一行。「// wait_for_kid v0.2 — demo for angel investor.」

敲完。赵世杰把键盘推回去。屏幕上最后一行输出。

「All tests passed. 47/47.」

郑国平看了屏幕三十秒。然后说了一句话。

"你用的这个设计模式——不是你在学校学的。"

"嗯。Linux内核的workqueue模型。简化版。适合嵌入式设备。"

"你知道workqueue——说明你看过内核源码。几岁开始看的。"

"十三。"

郑国平把眼镜摘下来。擦了擦。戴上。然后在一张名片背面写了一个号码。推到赵世杰面前。

"这是我的私人手机。不是公司座机。下周三——来我办公室。带上你的wait_for_kid——不要PPT。不要商业计划书。只要代码——和你这个人。"

赵世杰接过名片。什么都没说。只是把名片放进键盘下面。空格键刚好压住号码的前三位。

下午四点。角落里的那个女生走过来。MacBook抱在怀里。屏幕没关——上面是一段Python代码。爬虫。爬的是豆瓣读书的评论。

"你是赵世杰。"不是问句。是陈述。

"是。"

"刚才那段workqueue——你的锁机制写得不对。spinlock放在中断上下文里会死锁。你应该用mutex。"

赵世杰推了一下眼镜。"中断上下文里——mutex会睡眠。spinlock虽然危险——但我在进入临界区前关了本地中断。注释里有写。"

女生低头看了一下自己电脑上的代码。然后抬头。

"我没看注释。抱歉。"她停了一下。"你是清华的？"

"大一。计算机系。"

"我大三。软院。我叫苏晚。苏——不是输赢的输。是苏轼的苏。"

"赵世杰。吉——不是吉祥的吉。"

苏晚愣了一秒。然后笑了。声音不大——但很干净。像有人轻轻敲了一下音叉。

顾屿在旁边喝完最后一口咖啡。什么都没说。前世——他不认识苏晚。但这个名字他会记住。因为2020年——一个叫苏晚的人出现在了福布斯30岁以下科技精英榜单上。项目——AI编程教育。估值——十二亿。

下午五点。沙龙快结束了。

郑国平最后上台。只问了一个问题。

"今天——有一个人——让我想起了1998年的自己。不是因为年龄——是因为判断。判断一件事——判断一个人——判断一个还没出生的市场。1998年——没人信论坛能赚钱。2010年——没人信大学生能做好天使投资。但今天——我看到了一个。他的项目还在早期——他的团队平均年龄不到二十。但他做事的方式——不是在赌——是在算。"

他停了一下。扫了一眼全场。然后说。

"这个人叫顾屿。合理科技。大一新生。不管你们信不信——我信。不是因为他说服了我——是他已经在做的事让我看到了。合同。白板上的名字。一个一个被签下来的被投项目。"

台下有人鼓掌。稀稀落落——但有人在鼓掌。

顾屿没站起来。只是把咖啡杯推到一边。杯底在桌面上转了一圈——停了。

晚上七点。仓库。

赵世杰把郑国平的名片从键盘下面拿出来。放在白板上。贴在名字旁边——和那张「Ready。」便签并排。

周洋凑过来。"这张名片——值多少钱。"

"不知道。但他的上一个天使轮——五十万——变六亿。"

周洋想了三秒。"那这张名片——至少值一个烤鸭。全聚德的。不是外卖——堂食。"

全仓库笑了一秒。陈远摇头。周雅丽翻合同——没抬头。林若溪在电脑上改合同——嘴角动了一下。

顾屿站在白板前。看了一遍所有人的名字。然后拿起笔——在上面写了一行新字。

「天使轮关闭——第二轮。接触中。」

下面——两个名字。郑国平。苏晚。

然后他在苏晚名字旁边画了一个问号。不是不确定——是等待。等待一个十三岁就看过Linux内核源码的人——和二十三岁就会爬豆瓣评论的人——坐在一起——写第一行共同代码。

手机震了。王浩。

「赵建斌今天去了第二家私立医院。不是体检——是查病房。查的是方老师的病房——她下个月要做肺结节切除。赵建斌的人找到主治医生——问——方老师有没有提过一个叫顾屿的学生。医生说——没提过。提过一个叫苏明远的——说是个好老师。还有一个——叫王浩的——说——'嘴巴甜——但眼神不对。'」

顾屿看着这条消息。看了很久。然后把手机放下。在白板上「方老师」旁边写了一行字。

「记得我。也记得你。」

然后画了一条线。线下面——四个字。

「2012年。体检。」

晚上九点。顾屿走出仓库。

月亮不是弯的了。是圆的。满月。月光洒在清华的银杏叶上。每一片都像被镀了一层银。

手机又震了。这次不是王浩。是一个陌生号码。没有名字。只有一句话。

「郑总让我联系你。我有个项目——做了两年——快撑不下去了。但我不想卖。想找一个人——不是投资人——是合伙人。郑总说——你就是这样的人。」

顾屿回了一条。

「什么项目。」

「开源数据库。对标MySQL。但用了列式存储——查询快一百倍。我写了四年。一个人。没有团队。没有融资。只有一个三万Star的GitHub仓库。我叫陆衍。二十四岁。没有学历——高中毕业。」

顾屿站在紫荆公寓楼下。抬头看了一眼月亮。圆的。很大。

他回了三个字。

「周六。仓库。」

窗外的路灯又闪了一下。但这次不是钨丝老化。是电压。因为整个清华园的灯——都闪了一下。然后全亮了。比原来更亮。

像有人在配电房里——换了一个新的变压器。
